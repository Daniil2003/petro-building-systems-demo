# Демо-система: три участка + панель директора

Однофайловая рабочая система по задаче «Три таблицы — одна удобная система и панель руководителя».

Ниже — максимально подробная инструкция для человека, который **никогда не программировал**.
Просто выполняйте шаги по порядку и копируйте команды как есть.

---

## Что вообще происходит

Есть три участка (заготовка, сварка, документация), данные которых лежат в трёх Excel-файлах.
Наша система при **первом запуске** один раз переносит данные из этих трёх файлов в свою
локальную базу данных. После этого Excel-файлы системе больше не нужны — она работает сама,
а все правки сохраняются и переживают перезапуск.

Работает это так:

```
3 Excel-файла  ──►  система (Flask)  ──►  база данных data.db  ◄──►  экраны в браузере
   (нужны 1 раз)         программа          хранит все данные
```

---

## Шаг 0. Что понадобится

- Компьютер Mac (инструкция для macOS; на Windows команды чуть другие — см. раздел внизу).
- Терминал — это программа, где вводятся команды текстом. Открыть её так:
  нажмите `Cmd + Пробел`, наберите `Терминал` (или `Terminal`), нажмите `Enter`.
- Скачанные файлы системы: папка `demo` (внутри `app.py`), а рядом — три файла
  `01_Заготовка.xlsx`, `02_Потребность_сварки.xlsx`, `03_Документация.xlsx`.

Ничего покупать или устанавливать из интернета не нужно: Python уже есть в macOS.

---

## Шаг 1. Откройте терминал

`Cmd + Пробел` → наберите `Терминал` → `Enter`.

Вы увидите строку примерно такого вида (после неё мигает курсор):

```
ваше_имя@MacBook ~ %
```

Это приглашение ввести команду. Команды вводятся **по одной**, после каждой нажимайте `Enter`.

---

## Шаг 2. Перейдите в папку с системой

Нужно «зайти» в папку `demo`. Для этого есть команда `cd` (change directory — сменить папку).

Скопируйте **всю** строку ниже, вставьте в терминал и нажмите `Enter`:

```bash
cd ~/Documents/Для\ ворк/Задание/demo
```

> **Что тут важно понять.** Пробелы в пути «экранируются» обратным слэшем (`\ `) —
> иначе терминал подумает, что это две отдельные папки, и выдаст ошибку
> `cd: no such file or directory: demo`.
>
> **Совет.** Чтобы не ошибиться с путём: наберите `cd ` (с пробелом), затем просто
> **перетащите папку `demo` мышкой из Finder прямо в окно терминала** — путь
> подставится сам. После этого нажмите `Enter`.

> **Если путь отличается.** Если файлы лежат в другом месте, перетащите нужную папку
> в терминал, как описано в совете выше.

**Как понять, что всё получилось:** в приглашении появится слово `demo` в конце, например:

```
ваше_имя@MacBook demo %
```

Это значит, что вы «находитесь» внутри папки `demo`. Проверить при желании можно командой
`ls` (список файлов) — она покажет `app.py`, `README.md` и, возможно, `data.db`.

---

## Шаг 3. (Только первый раз) Поставьте две библиотеки

Библиотеки — это наборы готового кода, которые использует наша система.

Скопируйте строку целиком и нажмите `Enter`:

```bash
python3 -m pip install flask openpyxl
```

> **Важно про название команды.** В macOS это `python3` (а **не** `python`).
> Если ввести `python`, вы увидите `zsh: command not found: python` — это не поломка,
> просто правильное имя `python3`. То же самое с `pip` → пишите `pip3` или,
> как в команде выше, `python3 -m pip`.

Побежит текст установки. Дождитесь, пока снова появится приглашение с `demo %`.
Слова `Successfully installed ...` означают, что всё хорошо.

> Это нужно сделать **один раз**. В следующие разы этот шаг пропускайте.

---

## Шаг 4. Запустите систему

Введите (или скопируйте) и нажмите `Enter`:

```bash
python3 app.py
```

Вы увидите примерно такой текст:

```
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit
```

Это значит, что система **запущена и работает**. Терминал теперь «занят» — **не закрывайте
это окно** и не вводите в него новые команды, пока пользуетесь сайтом. Чтобы остановить
систему, нажмите в терминале `Control + C`.

> Если порт 5000 занят (на macOS его часто занимает системная служба AirPlay), система
> сама напишет об этом и предложит другой порт. Тогда запустите на порту 5055:
>
> ```bash
> PORT=5055 python3 app.py
> ```
>
> И открывайте адрес с 5055 вместо 5000 (см. следующий шаг).

---

## Шаг 5. Откройте систему в браузере

Откройте любой браузер (Safari, Chrome) и в строке адреса (где адреса сайтов) введите:

```
http://127.0.0.1:5000
```

(если запускали с `PORT=5055` — введите `http://127.0.0.1:5055`)

Нажмите `Enter`. Откроется **Панель генерального директора**.

> **Если «не работает» — почти всегда одна из трёх причин:**
> 1. Окно терминала, где вы запускали `python3 app.py`, было закрыто или остановлено —
>    тогда просто запустите его снова (Шаг 4).
> 2. В адресе опечатка: должно быть именно `http://127.0.0.1:5000`
>    (не `localhost` с запятой, без пробелов).
> 3. Вы указали не тот порт (`5000`, если запускали `PORT=5055 python3 app.py`, — тогда нужно `5055`).

## Экран за экраном: что где находится

Сверху есть меню с четырьмя кнопками:

| Кнопка в меню | Адрес | Что это |
|---|---|---|
| **Панель директора** | `/director` | KPI, графики, сводная таблица, проверка ошибок, скачивание отчёта |
| **Заготовка** | `/zag` | Экран участка заготовки: правка плана и факта |
| **Сварка** | `/weld` | Экран участка сварки: правка потребности |
| **Документация** | `/docs` | Экран участка документации (независимый) |

## Как поправить данные (это умеет любой сотрудник)

1. В меню выберите нужный участок (например, **Заготовка**).
2. В таблице найдите строку и впишите новые числа в поля справа (`план` и/или `факт`).
3. Нажмите кнопку 💾 рядом со строкой — значение сохранится, а панель директора
   **пересчитается автоматически**.
4. Кнопка ✕ удаляет запись, блок «＋ Новая запись» внизу добавляет строку.

## Панель директора: сценарий демонстрации (5 минут)

1. **Откройте** http://127.0.0.1:5000 — видны KPI, графики, сводная таблица по партиям
   и блок «⚠️ Проверка ошибок».
2. **Покажите проблему.** В учебных данных заложены специально испорченные значения.
   Кликните партию **LOT-03** в сводной таблице — откроется детализация, где у записи
   **P-003** стоит бейдж «выброс: факт > 3×план», а статус партии — «недостоверно».
3. **Исправьте.** Перейдите в **Заготовка**, в строке **P-003** впишите факт `95`, нажмите 💾.
4. **Покажите эффект.** Вернитесь на **Панель директора**:
   - факт заготовки вырос `290 → 385`;
   - выполнение плана `72% → 77%`;
   - партия **LOT-03** стала «дефицит 73%»;
   - а **Документация не изменилась** (26/18) — участки независимы.
5. **Детализация.** Кликните **LOT-03** ещё раз — обе записи теперь «ок».
6. **Отчёт.** Кнопка «Скачать отчёт Excel» сохранит файл с листами: KPI, покрытие,
   достоверные записи, ошибки. Рядом есть кнопка **CSV**.
7. **Живучесть (самая важная проверка).**
   - Остановите систему: в терминале нажмите `Control + C`.
   - Уберите (в Корзину) три Excel-файла `01_...`, `02_...`, `03_...`.
   - Запустите снова: `python3 app.py`.
   - Откройте браузер — **данные и ваши правки на месте**, система работает без Excel.

## Частые ошибки и что делать

| Сообщение в терминале | Причина | Решение |
|---|---|---|
| `zsh: command not found: python` | на macOS команда называется `python3` | пишите `python3` вместо `python` |
| `zsh: command not found: pip` | то же самое | используйте `python3 -m pip install flask openpyxl` |
| `cd: no such file or directory: demo` | вы не в той папке, или путь с пробелами | перетащите папку `demo` из Finder в терминал после слова `cd ` |
| `ModuleNotFoundError: No module named 'flask'` | не выполнен Шаг 3 | выполните `python3 -m pip install flask openpyxl` |
| Порт занят / `Address already in use` | на порту уже кто-то сидит | запустите `PORT=5055 python3 app.py` и откройте :5055 |
| Сайт по адресу не открывается | система не запущена или закрыто окно терминала | снова выполните Шаг 4, оставьте окно открытым |

## Если хочется начать «с нуля» (сбросить все правки)

Данные хранятся в файле `demo/data.db`. Чтобы вернуть исходное состояние из Excel:

1. Остановите систему (`Control + C`).
2. Удалите файл базы. В терминале (вы уже в папке `demo`):
   ```bash
   rm data.db
   ```
3. Запустите снова: `python3 app.py`. Данные заново импортируются из трёх Excel-файлов.

> Если Excel-файлы уже удалены, а `data.db` стёрт — восстанавливать будет нечего.
> Поэтому удаляйте `data.db` только когда рядом есть три исходных `.xlsx`.

## Запуск на Windows (кратко)

1. Установите Python с сайта python.org (при установке поставьте галочку **Add Python to PATH**).
2. Откройте «Командную строку» (Cmd → `cmd`).
3. Команды те же, но путь выглядит иначе, например:
   ```
   cd C:\Путь\к\папке\demo
   pip install flask openpyxl
   python app.py
   ```

## Файлы проекта

- `demo/app.py` — вся система (Flask + SQLite + SVG-графики + экспорт отчётов), ~950 строк.
- `demo/data.db` — база данных, создаётся автоматически при первом запуске.
- `01_Заготовка.xlsx`, `02_Потребность_сварки.xlsx`, `03_Документация.xlsx` — исходные данные,
  нужны только для первого импорта (и для сброса через удаление `data.db`).

## Расчёты (что и как считается)

- **Выполнение плана заготовки** = Σ факт / Σ план **только по достоверным** записям
  (не среднее процентов).
- **Покрытие партии** = факт заготовки / потребность сварки, связь **только по `batch_id`**.
  Если пары нет — статус «нет пары», связь не придумывается.
- **Документация — независимый участок**: её ошибки и правки не влияют на заготовку/сварку
  и наоборот.

## Проверка ошибок

| Код | Правило | Попадает в итоги? |
|---|---|---|
| дубликат `record_id` | один ID дважды (P-005) | ⛔ исключается |
| нет факта | пустая ячейка (P-007) | ⛔ исключается |
| отрицательный факт | факт < 0 (P-004: −5) | ⛔ исключается |
| выброс | факт > 3×план (P-003: 1200 при плане 100) | ⛔ исключается |
| факт = 0 | простой (P-006) | ⚠️ предупреждение, участвует |
| нет/плохой план | план пуст или ≤ 0 | ⛔ исключается |
| факт док. > плана | перевыполнение | ⚠️ предупреждение |

Ключевое правило: ошибка **исключает только свои записи**, а связанный показатель
(покрытие партии) помечается **«недостоверно»**, а не превращается в «достоверный»
дефицит/покрытие. Ошибка одного участка **не портит** итоги независимого участка.

## Технологии

Python 3.9+, Flask, SQLite (встроен в Python), openpyxl (импорт и экспорт Excel).
Графики — встроенные SVG, без библиотек и интернета. Зависимостей всего две:
`flask` и `openpyxl`.
